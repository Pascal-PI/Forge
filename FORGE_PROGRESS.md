## Implementation order

The source roadmap is the attached FORGE PDF and its pasted text. The table below follows those milestone numbers; a feature in a later build is not evidence that a differently numbered requirement is complete.

1. **1.5.1 / 1.6 / 1.7 — Lessons and revision:** presentation export is implemented; deepen evidence-grounded lesson sequencing and revision analysis.
2. **1.8 — Accounts and briefs:** blocked until the user selects an appropriate new Supabase project and approved email-verification/brief provider. Do not alter the unrelated connected project, bill, deploy or send mail.
3. **2.0–2.4 — Competition readiness and product experience:** improve contest readiness evidence and context-specific recommendations; add deeper focus workflows; finish accessibility, responsive, reliability and UX audits.
4. **2.5–2.9 — Contests and adaptive platform:** global contests/leaderboards require a reviewed backend and integrity design; local proposals, milestones, analytics, levels and Advent of Code can progress independently.
5. **3.0 — Advanced platform:** broaden language environments, progress statistics, optional voice, verified event discovery, privacy-protected leaderboards, accessibility, reliability, SEO and application security.
